# Slime Mold

Run a fleet of coding agents on one machine: long-lived agents with their own memory, a task queue, messaging between agents, and limits and recovery so the fleet can work while nobody watches.

Early work in progress; nothing here is usable yet.

## Development

```
just setup   # install dependencies and git hooks
just check   # lint, format check, type check, tests with coverage
```
